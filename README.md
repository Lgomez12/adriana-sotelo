# Adriana Sotelo

Presentación personal de Adriana Sotelo y su trayectoria en Rotary. Landing responsive en HTML, CSS y JavaScript, preparada para ser el destino de una tarjeta NFC.

## Archivos
- index.html: landing completa, con estilos, funciones, retrato y tipografías integrados.
- fotos/: carpeta para las futuras fotografías, con instrucciones.
- vercel.json: configuración de publicación estática.

## Ver la landing
Abrir index.html en un navegador. No requiere instalación ni compilación.

## Subir a GitHub desde la web
1. Descomprimir adriana-sotelo-repositorio.zip.
2. Abrir el repositorio Lgomez12/adriana-sotelo.
3. Elegir uploading an existing file (o Add file > Upload files).
4. Arrastrar el CONTENIDO de la carpeta adriana-sotelo: index.html, README.md, vercel.json y la carpeta fotos.
5. Confirmar con Commit changes.

El archivo index.html debe quedar en la raíz del repositorio, junto a fotos/. No subir el ZIP ni la carpeta contenedora como un nivel adicional.

## Publicar en Vercel
Importar el repositorio adriana-sotelo. Seleccionar Other como framework y dejar la raíz del proyecto como directorio. No necesita comando de instalación ni compilación; si se pide Output Directory, usar un punto (.).

## Agregar fotografías
Leer fotos/README.md. Las tarjetas de trayectoria usan la configuración TRAJECTORY_PHOTOS al final de index.html. Subir las fotos a fotos/ y completar su ruta en src.
