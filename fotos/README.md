# Fotografías

Guardar aquí las fotos de Adriana, su trayectoria y los proyectos.
Usar nombres sin espacios ni tildes: por ejemplo, presidencia-2025.jpg.

Para las tarjetas de trayectoria, buscar TRAJECTORY_PHOTOS al final de index.html y completar el campo src correspondiente:

src: 'fotos/presidencia-2025.jpg'

Las etapas van desde etapa-1 hasta etapa-12. Las tarjetas mantienen el espacio reservado hasta que se agregue una imagen válida.

Las fotografías de proyectos se incorporarán a sus secciones cuando estén disponibles. La foto actual de portada está integrada en el HTML.
